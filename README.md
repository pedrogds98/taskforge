Sobre o projeto

O TaskForge é um projeto desenvolvido ao longo da mentoria Do Código ao Contrato, construído gradualmente, aula após aula, colocando em prática os conhecimentos adquiridos durante o curso.

O projeto começou com uma aplicação simples e evoluiu para uma API REST integrada a um front-end, com autenticação, gerenciamento de usuários e operações de criação, consulta, atualização e exclusão de tarefas.
