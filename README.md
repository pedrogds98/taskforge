TaskForge

Uma aplicação de gerenciamento de tarefas desenvolvida aula após aula, com o apoio do curso Do Código ao Contrato.

🔗 [Aplicação online](https://taskforge-front-end.pages.dev)

📘 [Documentação da API (Swagger)](https://taskforge-7eqw.onrender.com/swagger-ui/index.html#/)

Sobre o projeto

O TaskForge é um projeto desenvolvido ao longo da mentoria Do Código ao Contrato, construído gradualmente, aula após aula, colocando em prática os conhecimentos adquiridos durante o curso.

O projeto evoluiu para uma aplicação web integrada a uma API REST, com autenticação, gerenciamento de usuários e operações de criação, consulta, atualização e exclusão de tarefas.
